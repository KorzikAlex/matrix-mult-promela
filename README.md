# ИДЗ №1

## Задание

Параллельный **алгоритм** умножения **двух** матриц:

- [x] Размер **n*n**.
- [ ] Для **Р** процессов 
- [ ] Параллельно вычислялись **столбцы** результирующей матрицы.
- [ ] Исходные матрицы **загружены** на процессы **заранее**.
- [ ] **Свойства:** Сформулировать свойства алгоритма на языке LTL
- [ ] **Разделяемые переменные:** Обмен данными, если он необходим, осуществляется с помощью разделяемых переменных.
- [ ] **Дополнение:** По завершении умножения 0-й процесс выводит результат.
- [ ] **Сложность:** средняя

## Установка зависимостей

P.S. `tcl` и `tk` должны быть 8 версии!

Для `Debian/Ubuntu`

```bash
sudo apt install yacc tcl tk gcc make
```

Для `Fedora`

```bash
sudo dnf install yacc tcl8 tk8 gcc make
```

## Установка Spin

Для `Debian`

```bash
sudo apt install spin
```

Для `Ubuntu/Fedora`

```bash
git clone https://github.com/nimble-code/Spin
cd Spin
make
sudo make install
```
