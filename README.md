# Установка зависимостей

P.S. `tcl` и `tk` должны быть 8 версии!

Для `Debian/Ubuntu`

```bash
sudo apt install yacc tcl tk gcc make
```

Для `Fedora`

```bash
sudo apt install spin yacc tcl8 tk8 gcc make
```

# Установка Spin

Для `Debian`

```bash
sudo apt install spin
```

Для `Ubuntu/Fedora`

```bash
git clone https://github.com/nimble-code/Spin
cd Spin
make
sudo make install
```
